Lumo Task is a full-stack task management app built around the Eisenhower Matrix, Pomodoro focus timer, and AI-assisted classification — available as a web app, PWA, and Windows desktop app.

> **100% AI-coded.** Every line of code, every commit, and every PR in this project was generated by [Claude (Anthropic)](https://claude.ai). This is a long-running experiment in AI-driven product development.

## Feature Highlights

| Feature | Description |
|---------|-------------|
| Today View | Recommended task card + completed timeline for the current day |
| Eisenhower Matrix | Drag-and-drop across all four quadrants (Q1–Q4) |
| Focus / Pomodoro | Full-screen focus mode with a Web Worker timer that survives tab switches |
| AI Classify | One-click LLM classification with heuristic fallback |
| Habit Check-in | Daily habit tracking with check-in dialog and badge |
| Onboarding | Guided 5-step onboarding flow for new users |
| Calendar Week View | Drag tasks onto the calendar to set due dates |
| Stats and Export | Stats page with shareable PNG export |
| Bilingual | Full EN / ZH UI with runtime language switching |
| Accent Theming | 4 accent colors, configurable per user |
| PWA | Installable, with offline shell support |
| Mobile Layout | Bottom tab bar optimized for mobile screens |
| Desktop App | Electron-based Windows installer |

## Quick Start

**Prerequisites:** Node.js 22+

```bash
git clone https://github.com/lumoryxr/lumo-task-web.git
cd lumo-task-web

# Start frontend + backend together
make dev-full
```

The web app runs at `http://localhost:5173` and the API at `http://localhost:3000`.

### Available Make Targets

| Command | Description |
|---------|-------------|
| `make dev` | Frontend only (`http://localhost:5173`) |
| `make dev-full` | Frontend + backend |
| `make backend-migrate` | Initialize the SQLite database |
| `make backend-seed` | Seed demo data |
| `make ci` | Typecheck + lint + build (mirrors CI) |

### Windows Desktop App

Download the latest `Lumo Task Setup x.x.x.exe` from [Releases](https://github.com/lumoryxr/lumo-task-web/releases) and run the installer.

> If Windows SmartScreen appears, click "More info" then "Run anyway".

## Deploy

Lumo Task uses **Vercel (frontend) + Render (backend)** on free tiers.

| Service | Platform | Config |
|---------|----------|--------|
| Frontend SPA | Vercel | `vercel.json` |
| Backend API | Render | `render.yaml` |

**Environment variables:**

```bash
# Vercel (frontend)
VITE_API_BASE=https://your-backend.onrender.com/v1

# Render (backend)
LUMO_JWT_SECRET=<generate a random secret>
LUMO_ALLOWED_ORIGINS=.vercel.app
NODE_VERSION=22
```

## CI/CD Pipeline

```
Pull Request
 └── GitHub Actions CI
      ├── TypeScript type-check (frontend + backend)
      ├── ESLint
      ├── Vite build verification
      ├── Backend compile (tsc + esbuild)
      └── npm audit security scan

Merge to main
 ├── Vercel auto-deploys frontend (production)
 ├── Render auto-deploys backend (production)
 └── GitHub Actions packages Windows installer → GitHub Releases
```
